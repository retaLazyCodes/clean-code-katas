# Gilded Rose Kata (Refactoring orientado a SOLID)

Este proyecto consiste en la resolución de la clásica [Gilded Rose Kata](http://kata-log.rocks/gilded-rose-kata), con un enfoque específico en **refactorizar el código aplicando principios SOLID y patrones de diseño**, **sin seguir estrictamente el enfoque propuesto por la kata** ni utilizar **TDD** como metodología principal.

## Objetivo

El objetivo de este ejercicio es mejorar la legibilidad, mantenibilidad y extensibilidad del código original de Gilded Rose, identificando y aplicando principios de diseño como:

- Principios SOLID
- Principios de diseño orientado a objetos
- Aplicación selectiva de patrones de diseño

## Qué no incluye

- No se aplica TDD como técnica principal de desarrollo.
- No se sigue al pie de la letra la estructura original de la kata.
- No se busca una solución "canónica", sino una interpretación personal centrada en el diseño del código.

## Cómo correr el proyecto

```bash
npm install
npm run test # ejecutar tests
npm start # ejecutar app CLI
```
